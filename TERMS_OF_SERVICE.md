## 2. Description of Service
**Lạc Trôi~,~** is a specialized community utility Discord bot created by **VoThien** to provide:
1. **Opt-in Mention Alerts:** Private Direct Message (DM) notifications containing jump-links whenever a subscribed user is mentioned (`@mention`) in server channels.
2. **Game Recommendations:** Periodic (every 3 hours) and on-demand (`/goiy`) random game suggestions delivered discreetly via 1-on-1 private DMs.
3. **Forum Thread Indexing:** Reading titles of game releases from administrator-approved forum channels without altering or reopening archived threads.
4. **Interactive In-DM Search:** Game search assistance with fuzzy keyword matching and acronym support.
5. **Auto-Cleaning DMs:** Automatic cleanup and self-deletion of recommendation messages to avoid cluttering user inboxes.
