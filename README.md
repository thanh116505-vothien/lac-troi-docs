### Core Bot Features Covered
- **Opt-in Mention Notifications:** Instant private DM alerts with jump links when mentioned.
- **Game Recommendations:** 5 random game suggestions every 3 hours or on-demand via private DM.
- **Forum Indexing without Unarchiving:** Passive title reading without reopening closed posts.
- **In-Memory Search & Self-Cleaning DMs:** Real-time query matching without permanent chat log storage.
